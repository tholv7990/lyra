LYRA — LOGO KIT

FILES
  Primary logo (icon + wordmark)
    lyra-logo-horizontal-dark.svg / .png   for dark backgrounds
    lyra-logo-horizontal-light.svg / .png  for light backgrounds
    lyra-logo-stacked-dark.svg             icon above wordmark — square/centered spots, avatars

  Wordmark only ("Lyra")
    lyra-wordmark-dark.svg     off-white, on dark
    lyra-wordmark-light.svg    near-black, on light
    lyra-wordmark-white.svg    pure white (single-colour)
    lyra-wordmark-black.svg    pure black (single-colour)
    lyra-wordmark-accent-dark.svg / -light.svg   with the orange "L" accent
    lyra-wordmark-dark.png / -light.png          transparent PNG

  Mark only
    lyra-mark.svg / .png          bare orange "Ly" monogram (no tile) — for dark surfaces
    lyra-mark-squircle.svg        the app-icon tile (same art as the favicon)

COLOUR
  Orange  #FF6B1A   accent — lives in the mark, used scarcely
  Ink     #F5F5F7   off-white wordmark on dark
  Ink-dk  #0A0A0A   near-black wordmark on light

CLEAR SPACE
  Keep padding of at least the height of the "L" on all sides.
  (The SVGs already include safe padding.)

MINIMUM SIZE
  Horizontal logo  >= 160px wide      Wordmark  >= 110px wide      Icon alone  >= 24px

DON'TS
  Don't recolour the wordmark or the orange. Don't add shadows/effects
  (the icon glow is built in). Don't stretch, rotate, or rearrange the lockup.
  Don't put the dark icon on a busy or low-contrast background.

TYPE
  Wordmark is set in Poppins as a stand-in — Inter isn't installed in this build
  environment. The design system specifies Inter; ask and the whole kit can be
  regenerated cut from real Inter outlines.
